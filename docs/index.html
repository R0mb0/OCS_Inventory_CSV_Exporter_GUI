Scheduled OCS Inventory exports, on autopilot.

A Windows desktop app that logs into OCS Inventory NG, exports a full CSV on a schedule, cleans up old files on its own, and comes back after a reboot — no one needs to be watching.

📦 View source on GitHub ⬇️ Get the latest release

What it does

Everything the original PowerShell script did, plus a control panel that runs it for you.

🧩

Layered, resizable GUI

Connection, loop interval and output settings stacked in three sections you can resize by dragging the dividers.

⏱️

Scheduled extraction loop

Set an interval in minutes or hours; press the green Avvia button and it keeps exporting until you press Stop.

🧹

Automatic cleanup

Keep only the last N CSV files and/or delete files older than a set period — both rules can run together.

🔒

Encrypted credentials

The OCS password is encrypted at rest with Windows DPAPI — never written to disk in plain text.

🌓

Follows your OS theme

Light and dark mode are detected automatically, with a manual override saved for next time.

🔁

Survives a reboot

An --autostart flag and example launcher get the export loop running again on its own after the server restarts.

How it works

The same automation flow as the original ocs_export.ps1 script, now orchestrated by the app.

Log in

Signs into OCS Inventory NG using the credentials you configured.

Open advanced search

Navigates to the advanced search page for the inventory table.

Enable every column

Toggles every available column so the export is always complete.

Export the CSV

Triggers the export and saves the file with a timestamped name.

Clean up old files

Applies your cleanup rules to the output folder, if enabled.

Wait and repeat

Sleeps for the configured interval, then starts the next cycle.

Requirements

  • Windows 10 or 11
  • Python 3.10+ (if running from source)
  • Network access to your OCS Inventory instance
  • A valid OCS Inventory user account
